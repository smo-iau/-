# 🎭 أقنعة

لعبة ويب جماعية لحظية (حتى 30 لاعب): كل لاعب يسوي شخصية وهمية، يتحاورون بأسماء شخصياتهم، وفي النهاية يصوّتون ويخمّنون مين صاحب كل قناع.

## التشغيل على جهازك

يحتاج Node.js 18 أو أحدث.

```bash
npm install
npm start
```

افتح `http://localhost:3000`. عشان يدخل أصحابك من جوالاتهم على نفس الشبكة، استخدم عنوان جهازك (مثل `http://192.168.1.20:3000`).

## النشر على الإنترنت

أي استضافة تدعم Node و WebSocket تنفع. أسهلها:

- **Render.com**: ارفع المجلد على GitHub ← New Web Service ← Build: `npm install` ← Start: `npm start`.
- **Railway / Fly.io**: يتعرفون على `Dockerfile` الموجود تلقائيًا.

مهم: شغّل نسخة وحدة فقط من الخادم (instance واحد)، لأن الغرف محفوظة في الذاكرة. إعادة تشغيل الخادم تمسح الغرف الحالية.

## قائمة الأسماء

الأسماء الافتراضية في `names.default.json`. تطلع للاعبين عند الدخول (يختار اسمه منها) وتطلع خيارات في مرحلة التخمين. المضيف يقدر يعدّلها من لوحة التحكم ⚙️ ← الأسماء أثناء اللعب.

## لوحة تحكم المضيف

- التنقل بين المراحل (التالي، السابق، أو القفز لأي مرحلة).
- اللاعبين: مين متصل، مين خلّص، مين جاوب/صوّت/خمّن، الطرد، والسماح للمطرودين بالرجوع.
- الأسئلة: بنك أسئلة جاهزة، مؤقت اختياري، زيادة أو نقص 30 ثانية، إلغاء المؤقت، تعديل السؤال، قفله وإعادة فتحه، وحذف أي رسالة.
- التصويت والتخمين: قفل/فتح، تصفير، وعرض عدد الأصوات للمضيف فقط.
- إعدادات: الدخول بالاختيار من القائمة، السماح بالدخول المتأخر، إظهار عدّاد المجاوبين للاعبين.
- إعادة اللعبة بنفس اللاعبين.

## السرية

الخادم ما يرسل لأي جهاز (حتى المضيف) مين صاحب كل شخصية إلا في مرحلة النتائج، وكل واحد بعد نزع قناعه. الأصوات ما تنرسل للاعبين قبل النتائج. صلاحيات المضيف مربوطة برمز سري يُعطى لجهاز المضيف فقط.

## التصويت (وضع الإقصاء)

- كل لاعب يختار شخصية ويخمّن مين صاحبها.
- اللي ينعرف صاحبها صح يطلع وينكشف (مو الأكثر أصوات). المضيف يضغط «🎯 اكشف اللي انعرفوا صح».
- اللي يطلع ما يقدر يصوّت بعدها.

## النقاط

- وضع الإقصاء: كل تخمين صحيح وقت التصويت = نقطتين
- بدون وضع الإقصاء: كل صوت لشخصيتك = نقطة
- كل تخمين صحيح = نقطتين
- إذا ما أحد عرف شخصيتك = 3 نقاط ولقب «سيد التمويه»
